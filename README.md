# Особенный день ✦

Поздравительное мини-приложение на русском: пять уровней: кодовый сейф, шесть пар карточек, повторение ритма, логические вопросы и созвездие и личное письмо в финале. Работает на телефоне и компьютере, без регистрации, сервера данных и зависимостей.

## Запуск

Откройте `index.html` в браузере или выполните в каталоге проекта:

```sh
python -m http.server 8000 --bind 0.0.0.0
```

## Персонализация

В начале `app.js` измените объект `greeting`: имя (`name`), заголовок (`title`), абзацы пожеланий (`paragraphs`) и подпись (`signature`). Сейчас приложение настроено для Кирилла: 29-летие, дружеский шутливый тон.

## Как поделиться

Разместите `index.html`, `style.css` и `app.js` на любом статическом хостинге, например GitHub Pages. После публикации ссылку можно отправить имениннику или открыть внутри Telegram. Интеграция с Telegram Bot API не требуется для обычной ссылки; меню Mini App настраивается отдельно через BotFather.

Фоновая мелодия и звуки нажатий включаются кнопкой ♪ / ♫. Для запуска нужно нажатие пользователя (правило мобильных браузеров). Мелодия синтезируется в браузере и не требует загрузки аудиофайлов. При отключённом интернете используется системный шрифт. Прогресс хранится только до перезагрузки страницы; финальное письмо не защищено паролем и доступно в исходном коде.
